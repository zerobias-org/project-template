## How to write a requirement

- One testable statement per requirement, with SHALL.
- Give each requirement the next id: `REQ-001`, `REQ-002`, and so on. Never reuse or change an id.
- To change a requirement, record a decision first. Then increase its version and add the date.
- Do not delete a requirement. Set its status to `retired`.
